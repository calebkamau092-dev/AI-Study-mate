# AI StudyMate

AI StudyMate is a Python CLI study assistant that uses AI to help students learn Python.

## Features

- Sign up and login
- AI-powered Python explanations
- AI-generated quizzes
- Personalized study plans
- Quiz progress tracking
- JSON data storage

## Built With

- Python
- Ollama
- Llama 3.2
- Pytest
- JSON

## Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Download the AI model:

```bash
ollama pull llama3.2
```

Run AI StudyMate:

```bash
python main.py
```
